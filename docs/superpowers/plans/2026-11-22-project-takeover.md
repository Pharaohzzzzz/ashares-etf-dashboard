# ETF 资金雷达项目接手计划书

本轮目标是建立项目现状基线，交付一份有证据、可排序、可验收的新增、优化和删除建议。审查范围包含客户端、服务端、数据与调度、Windows 运维、测试和现有文档。执行方式为一名子 Agent 审查，项目经理复核关键证据并交付报告。

## 执行步骤

1. 盘点项目当前入口、功能、数据链路、存储与运行方式，区分已上线到本地版本的能力、代码中的限制和历史整改记录。
2. 通过现有测试、本机只读检查与代码路径，验证监控池、行情与官方份额、IOPV、信号、同步状态、备份恢复和前端关键流程。记录验证条件、结果与尚未覆盖的场景。
3. 按用户影响和依赖关系整理新增、优化、删除建议。每项提供依据、优先级、范围及可观察的验收结果。删除建议说明依赖、替代方式及历史数据影响。
4. 复核影响首批排期的证据，产出项目现状报告和分阶段路线图。

## 范围与交付

- 审查源码、测试与本机状态。临时验证使用测试数据或数据库副本，保持正在使用的服务和数据库状态。
- 本轮交付接手审查及建议，功能变更和删除另行排期。
- 完成条件为形成模块与数据流地图、记录当前验证结果，并为优先事项给出可执行的验收标准。
